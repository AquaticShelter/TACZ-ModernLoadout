# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful in issues, pull requests, discussions and anywhere else you represent the project. Critique code and ideas, not
people. Harassment, personal attacks, discriminatory language and posting someone's private information are not accepted.

## Reporting

If someone's behaviour is a problem, contact the maintainer privately through GitHub (a private security advisory on this repository
reaches the maintainer only, or a direct message on the project's Discord / CurseForge page if one is linked in the README). Please
include links or screenshots. Reports are handled in confidence.

## Enforcement

The maintainer may edit or remove comments, close threads, and block people from the repository, following the enforcement guidelines
of the Contributor Covenant (correction, warning, temporary ban, permanent ban), depending on how serious and how repeated the behaviour is.
