# Playing

## Opening the loadout

<kbd>L</kbd> (rebindable under Controls, MW Loadout), the LOADOUT button in the top-left of the pause menu, or `/mwloadout`.

## Classes

Each player has their own saved classes (20 by default, the server can change that). A class is a full set of slots,
perks and the guns' attachments. Right-click a class for the menu:

| Entry | What it does |
|---|---|
| Equip | Put this class on you now (if the rules allow it, see below) |
| Randomize | Fill the class with random valid picks |
| Reset to default | Back to the server's default for each slot |
| Strip everything | Empty every slot |
| Pin to top | Keep it at the top of the list |
| Duplicate class | Copy it, then edit the copy |
| Delete class | Remove it |

Keys: <kbd>Up</kbd> / <kbd>Down</kbd> change class, <kbd>Enter</kbd> equips, <kbd>Delete</kbd> removes, <kbd>Tab</kbd> pins
the class list open or shut, <kbd>Esc</kbd> closes the right-click menu first and the screen second.

## Slots

Primary, secondary, melee, consumable, lethal, tactical, and three Field Upgrade slots that stay hidden until the
server enables them. What each slot accepts (categories, whitelist, blacklist, counts, locked or hidden) is set by the
server, so two servers can look quite different.

## Save, equip and respawn

- **Save** always works. Your class is stored on the server.
- **Equip** puts the class on you immediately when the edit rules allow it.
- If they do not, the class is remembered and **applied at your next respawn**. The screen tells you which rule blocked it.
- A respawn rebuilds your gear from the class, so you never keep an old copy of something.

## When can I change loadout?

The server decides. By default you can change it:

- for a few seconds after you respawn,
- once you have gone a while without taking damage,
- inside an edit zone an admin placed,
- in creative or spectator, and on Peaceful.

There is also a **use lock**: once you fire, throw or consume loadout gear, you cannot swap class to get a free refill.

## Progression

If the server has levels on, you gain player levels and each gun gains its own levels from kills. Some attachments need a
weapon level to unlock. Level-ups show as toasts.

## Ammo

Your starting reserve for a gun comes from its magazine size and a multiplier that depends on that size. Fit an
extended magazine in the gunsmith and the reserve is recalculated with it. See [Gunsmith](Gunsmith.md).
